# Home SOC Lab | Security Operations & Detection Engineering

## Overview

A hands-on SOC lab designed to simulate cyberattacks, collect endpoint telemetry, develop security detections, investigate alerts, and document incident response procedures.

The objective is to develop practical skills in security monitoring, threat detection, incident investigation, and response.

## Project Objectives

- Build a virtual security monitoring environment.
- Simulate controlled attack scenarios.
- Collect and analyse Windows endpoint telemetry.
- Develop detection rules using Kusto Query Language (KQL).
- Investigate security alerts and identify indicators of compromise.
- Document incident response and remediation procedures.
